## 2025-02-27 - [HIGH] Insecure Direct Object Reference (IDOR) in Research Chat API Routes
**Vulnerability:** Found IDOR vulnerabilities in `src/app/api/research/chat/update_name/[id]/route.ts` and `src/app/api/research/chat/delete_chat/[id]/route.ts`. The routes were taking the chat ID from the request params and updating or deleting the chat without first verifying that the authenticated user actually owned the chat.
**Learning:** Next.js API routes with database operations (like Mongoose `findByIdAndUpdate` or `findByIdAndDelete`) must always scope their queries to the authenticated user's ID (`userId`) to prevent unauthorized access or modification, especially for operations handling resource modification or deletion.
**Prevention:** Always use `findOneAndUpdate` or `findOneAndDelete` with `{ _id: id, userId: user._id }` instead of `findById...` when operating on user-owned resources, and ensure the user's authentication is validated at the start of the route handler.
